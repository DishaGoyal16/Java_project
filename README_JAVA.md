# SCMS local Java integration

This is the main local application. Start it from this folder with:

```powershell
.\scripts\Start-SCMS.ps1 -Demo -Diagnostics
```

The setup guide, testing results, cleanup summary and professor demonstration guide are in `java_docs/`. The original React and Flutter clients remain in `code/`; Java rules are in `code/java-rules/`, and FastAPI remains in `code/backend/`. No remote Git changes were made.
